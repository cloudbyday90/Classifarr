### Changed

- **The dead CommonJS settings test-router wrapper has been removed, and the live test harness now stands on the native ESM helper only** — the unused `createSettingsTestRouter.js` compatibility wrapper under `server/src/__tests__/setup` has been deleted. The remaining settings-route suites already use `createSettingsTestRouter.mjs`, so the test harness no longer carries a parallel CommonJS entrypoint for the same router-construction logic. (`server/src/__tests__/setup/createSettingsTestRouter.js`, `server/src/__tests__/setup/createSettingsTestRouter.mjs`)

- **More tests now use explicit `.mjs` database imports, and the integration Jest config now discovers `.mjs` integration suites** — `classificationPhaseService.test.mjs`, `integration/plexOAuth.test.mjs`, and `integration/policy-custom-signals.test.mjs` no longer rely on extensionless `../../config/database` imports, and `jest.integration.config.js` now matches both `.test.js` and `.test.mjs` files under the integration test tree. This keeps the test harness aligned with Node’s explicit ESM specifier rules and removes another compatibility-shaped gap between test wiring and runtime module resolution. (`server/src/__tests__/classificationPhaseService.test.mjs`, `server/src/__tests__/integration/plexOAuth.test.mjs`, `server/src/__tests__/integration/policy-custom-signals.test.mjs`, `server/jest.integration.config.js`)

- **More focused ESM suites now destructure defaults directly instead of reading `.default` inline from `await import(...)`** — `policies-threshold-routes.test.mjs`, `policies-routes.coverage.test.mjs`, `runtimeSettings.test.mjs`, and the shared `createSettingsTestRouter.mjs` helper now bind default exports with direct destructuring rather than evaluating `(...).default` after import resolution. This keeps the remaining harness-side dynamic imports closer to the runtime module contract without changing the test mock boundaries. (`server/src/__tests__/policies-threshold-routes.test.mjs`, `server/src/__tests__/policies-routes.coverage.test.mjs`, `server/src/__tests__/runtimeSettings.test.mjs`, `server/src/__tests__/setup/createSettingsTestRouter.mjs`)

(`server/src/__tests__/agreementMultiplier.test.mjs`, `server/src/__tests__/scheduler.test.mjs`, `server/src/__tests__/schedulerService.test.mjs`, `server/src/__tests__/v037.1-regression.test.mjs`)
