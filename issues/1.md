## Problem
Dashboard 'Classification Methods' section is inaccurate (see Issue #190):
- Shows outdated/hardcoded names ("Exact Match", "Learned", etc.)
- Only counts from 8 recent items, not all time
- Does not handle methods dynamically or update labels as new engines are added

Average Confidence is currently calculated in the frontend, potentially inconsistently and only from per-method stats.

## Solution
- [ ] Backend: Add `byMethod` per-method breakdown to `/api/stats` (`method`, `count`, `avg_confidence`)
- [ ] Frontend: Use this data to (a) display all actual methods, with accurate color/symbol, and (b) compute a proper weighted average confidence.
- [ ] Remove hardcoded names; list should expand/shrink as methods change.
- [ ] Add tooltips or info explaining what each method is.
- [ ] Review/adjust color-coding for new methods.
- [ ] Make method display and average confidence available to other pages/statistics.

## Backend Implementation

```javascript
// server/src/routes/stats.js
async function getOverallStats() {
  const overall = await db.query(`
    SELECT 
      COUNT(*) as total,
      ROUND(AVG(confidence)::numeric, 1) as avg_confidence,
      COUNT(CASE WHEN confidence >= 90 THEN 1 END) as high_confidence,
      COUNT(CASE WHEN confidence < 50 THEN 1 END) as low_confidence,
      COUNT(CASE WHEN created_at > NOW() - INTERVAL '24 hours' THEN 1 END) as last_24h,
      COUNT(CASE WHEN created_at > NOW() - INTERVAL '7 days' THEN 1 END) as last_7d
    FROM classification_history
  `);

  const byMethod = await db.query(`
    SELECT 
      method,
      COUNT(*) as count,
      ROUND(AVG(confidence)::numeric, 1) as avg_confidence
    FROM classification_history
    GROUP BY method
    ORDER BY count DESC
  `);

  return {
    ...overall.rows[0],
    byMethod: byMethod.rows
  };
}
```

```javascript
const sortedMethods = computed(() => {
  if (!stats.value.byMethod) return []
  return [...stats.value.byMethod].sort((a, b) => b.count - a.count)
})

const formatMethodName = (method) => {
  const names = {
    'source_library': 'Source Library',
    'policy_engine': 'Policy Engine',
    'rag_similarity': 'RAG Similarity',
    'exact_match': 'Exact Match',
    'learned_pattern': 'Learning Patterns',
    'manual_classification': 'Manual Override',
    'ai_verified': 'AI Verified',
    'ai_analysis': 'AI Analysis'
  }
  return names[method] || method.replace(/_/g, ' ').replace(/\b\w/g, l => l.toUpperCase())
}

const getMethodIcon = (method) => {
  const icons = {
    'source_library': '📂',
    'policy_engine': '⚙️',
    'rag_similarity': '🧠',
    'exact_match': '🎯',
    'learned_pattern': '📚',
    'manual_classification': '👤',
    'ai_verified': '🤖',
    'ai_analysis': '🤖'
  }
  return icons[method] || '❓'
}

const getMethodColor = (method) => {
  const colors = {
    'source_library': 'text-cyan-400',
    'policy_engine': 'text-purple-400',
    'rag_similarity': 'text-yellow-400',
    'exact_match': 'text-green-400',
    'learned_pattern': 'text-blue-400',
    'manual_classification': 'text-red-400',
    'ai_verified': 'text-amber-400',
    'ai_analysis': 'text-lime-400'
  }
  return colors[method] || 'text-gray-400'
}

const computedAvgConfidence = computed(() => {
  return Math.round(parseFloat(stats.value.avg_confidence || 0))
})
```
