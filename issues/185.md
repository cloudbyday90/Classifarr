## Summary

Enhance the Classification Details modal to show a **Classification Signals** breakdown panel, visualizing each engine's contribution (Preset, Profile, Pattern, RAG, History) for every AI/Policy classification.

**Problem:** The UI code exists (`SignalRow.vue`, signal breakdown section in `History.vue`), but this panel is **not visible** because the backend is not consistently storing `classification_details` data with scores and weights in the metadata.

---

## Requirements

### Backend
- Always include a `classification_details` object in the `metadata` for any AI/Policy-engine-driven classification
- Must have all keys: `scores` (all 5 engines, 0 if not run), `weights`, `method`
- Example structure:
```json
{
  "classification_details": {
    "scores": {
      "preset": 80,
      "profile": 60,
      "pattern": 0,
      "rag": 0,
      "history": 0
    },
    "weights": {
      "preset": 0.35,
      "profile": 0.25,
      "pattern": 0.15,
      "rag": 0.15,
      "history": 0.10
    },
    "method": "policy_engine",
    "processing_time_ms": 2140
  }
}
```
- Validate all classification code paths ensure this structure is populated
- File: `server/src/services/classification.js` (around lines 1431-1466)

### Frontend
- The "🔬 Classification Signals" panel should render whenever `classification_details.scores` exists
- Use `SignalRow.vue` for each of the 5 engines
- Display for each engine:
  - Score percentage and color-coded progress bar (if score > 0)
  - Grayed-out bar and "(not used)" label (if score = 0)
  - Weight multiplier (e.g., ×0.35)
- Show "Combined Score" at bottom
- Add tooltips explaining what each engine does
- Must be keyboard/ARIA accessible
- Files: `client/src/views/History.vue` (lines 181-196), `client/src/components/history/SignalRow.vue`

### Testing
- Backend test: Verify `classification_details` is stored correctly in metadata for all policy engine classifications
- Frontend test: Component renders signal breakdown when data exists, hides when missing
- Integration test: End-to-end classification stores and displays signals correctly
- Test with all engines active and with some engines at 0

### Documentation
- Update CHANGELOG.md under "Added" section
- Add before/after screenshots to PR
- Document what each engine type means (inline tooltips or help section)

describe('Classification Service', () => {
  it('should store classification_details in metadata', async () => {
