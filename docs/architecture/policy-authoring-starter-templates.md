# Policy Authoring Starter Templates

Status: superseded by the implemented [Policy Starter Template Intent
Boundary](policy-starter-template-intent-boundary.md).

Starter templates are no longer an operator selection or attachment mechanism.
The authoritative current design is a server-owned, source-labelled suggestion
projection followed by explicit typed intent commands. Existing preset
attachments remain readable and round-trip only through the compatibility
bridge until native storage replaces them.

This document remains as a historical design record. It must not be used to
restore a raw template browser, template attachment operation, or client-side
template-to-intent translation path.
