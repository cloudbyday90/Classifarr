## Behavior and limits

Three small leaves separate closed projection, live collection and held-reference
reading. The production evaluator observes actual policy/evaluation pairs and
retains proof against its final result after the existing diagnostic collectors.
Native authority/revision and compatibility origin remain distinct. A native
purpose contribution is not an extra requirement for generic evaluated advice.

The policy owner holds the exact result/item/context/destination and rechecks it
before AI-failure recovery advice. Missing, copied, replayed, changed, malformed
or overflowing evidence yields no suggestion. Existing high-confidence
non-transient recovery then uses neutral review. The reader does not rewrite
confidence or retry inputs; conservative confidence zero stays zero even with a
positive leading score. Neutral output retains the existing fallback method and
confidence 50, independently of that unchanged retry decision. Normal context
building, prompt/profile consumers, legacy
advice, scoring and route/learning authority are unchanged.

Collections remain complete within 64 evaluated/ranked candidates, 64 pool
libraries and a combined 16-KiB closed snapshot. Own data descriptors avoid
accessors/coercion; proxies and unsupported records are refused. Ordinary records
from another JavaScript realm remain supported. Names and pool ordering are not
identity. No raw terms, rules, item text, logs, provider fields or persistent
reference are added. Diagnostic capture availability is independent.

The reference assesses loaded headers and retained numeric values, not every
metadata/configuration property or database freshness after a provider call.
Process restart/serialization loses it. Existing independent policy review
metadata and its presentation safeguards remain unchanged; this batch binds the
recovery result's library suggestion, not every review or prompt consumer.
Pending History rows still leave the completed destination unset until an
explicit resolution. No new operator step, UI, API, schema, job or CLI trigger.
