## Implemented result

- Freeze versioned purpose/match diagnostics at synchronous native evaluation,
  reusing existing declared-rule scoring and combination semantics. Bind live
  refinement to the same typed item, candidate and loaded contract.
- Carry diagnostics through existing specialization/persistence. Require actual
  classifier-owned History method/capture origin and final ranked binding before
  interpreting them as proof.
- Return v2 cards through existing pending/library-comparison responses. Keep
  five source rows and fixed public categories; show inferred, mixed, unknown
  and legacy origins explicitly alongside constraint warnings.
- Preserve actual card versions and validate raw/normalized client paths.
  Correct adjacent decision and numeric display wording, preserving numeric
  identifiers, contributions, weights and reconstruction.
- Isolate the original heuristic in a named legacy producer. Correction signal
  snapshots/attribution stay v1 with their original statistics semantics.

No database/capture version, endpoint, job, provider call, saved report or private
CLI cohort change was added. Scores, ranking, thresholds, routing and learning
authority remain unchanged. Historical evidence is not rewritten or upgraded;
immutable policy capture v1 lacks declared-subset match proof.
