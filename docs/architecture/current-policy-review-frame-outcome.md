## Result

New accepted non-adopted RAG reruns carry a private receipt for the fresh policy
evaluation. The RAG owner publishes it after exact apply selection and rollout
settlement. The PolicyPath owner transfers that receipt across its known copy.
Other copies retain only an attempt marker and therefore produce a gap.

The History writer rechecks evidence at entry, after state derivation and inside
the insertion callback. A small SQL leaf assigns the normal sequence ID once
and uses it for both the row and JSONB frame in the existing transaction. The
ordinary writer retains its literal SQL path. Transaction acknowledgement
supplies bound notification metadata without a History reread.

The shared review resolver supplies recommendation, score, thresholds, card,
fixed support facts and library comparison. The confidence-notification path
delegates these scoped pending decisions to the same pending Discord builder.
Existing candidate choices and completed receipt recovery retain their meaning.
The root original `metadata.policyResult` remains separate. Missing or invalid
current evidence requires explicit selection; absence of the new field keeps
the legacy reader behavior.

The closed frame allows 64 numeric candidates, five detailed projections and
64 KiB, including PostgreSQL's expanded JSONB representation. Native purpose
categories come from the genuine immutable v2 capture; missing proof stays
unknown. Score explanations admit legitimate producer rounding, including a
100.2 rounded base. Raw rules, retrieved content and provider text are excluded.
