# Security Policy

## Supported Versions

Security fixes are applied to the latest release line. Older versions may not receive patches.

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report vulnerabilities privately.

1. Open a private GitHub Security Advisory in this repository:
   `Security` tab -> `Report a vulnerability`.
2. Include clear reproduction steps, impact, and affected version.
3. If possible, include a minimal proof-of-concept.

Do not open public issues for security vulnerabilities.

## Response Targets

- Initial triage response: within 72 hours
- Status updates: at least weekly until resolution
- Public disclosure: after a fix is available and users have had time to upgrade

## Disclosure and Credits

- Coordinated disclosure is preferred.
- Reporter credit is provided in release notes/changelog unless you request to remain anonymous.
